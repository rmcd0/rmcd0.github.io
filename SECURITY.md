# Security

Joran generates static files: there is no server-side code, database or login in a Joran site. Security issues are still possible, for example a way to inject script through content or configuration, or a vulnerable dependency in the build.

## Supported versions

The latest `1.x` release receives fixes.

## Reporting a vulnerability

Please **do not open a public issue**. Use GitHub's [private vulnerability reporting](https://github.com/rmcd0/joran/security/advisories/new) instead. Once a fix is released, the advisory is published with credit to you, if you wish.
