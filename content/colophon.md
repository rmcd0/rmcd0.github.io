How this site is made.

## Build

Static HTML generated by [Eleventy](https://www.11ty.dev/) from Markdown files, with the [Joran]({{ joran.homepage }}) theme (version {{ joran.version }}). No database, no server-side code: every page is a file.

## Typography

[Inter](https://rsms.me/inter/) for text, [IBM Plex Mono](https://www.ibm.com/plex/) for dates and code, [VT323](https://fonts.google.com/specimen/VT323) for a secret theme. All served from this site.

## Icons

[Tabler Icons](https://tabler.io/icons) (MIT).
