A /uses page lists the hardware and software you use. Here is what this demo is made of.

## Site

- [Eleventy](https://www.11ty.dev/) builds the pages from Markdown files.
- [GitHub Pages](https://pages.github.com/) hosts them, published by a GitHub Actions workflow.
- Images are resized by [eleventy-img](https://www.11ty.dev/docs/plugins/image/).

## Writing

- Any text editor. Markdown files, one per post, in `content/posts/`.
- `npm run new -- "My title"` creates the file with its front matter.
