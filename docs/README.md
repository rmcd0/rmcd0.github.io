# Joran documentation

Start with **[Getting started](getting-started.md)**. The other pages are references: read them when you need them.

## Use

1. [Getting started](getting-started.md): from the template to your site online, step by step.
2. [Configuration](configuration.md): every option of `content/site.config.js`.
3. [Writing](writing.md): posts, pages, front matter, types, tags, drafts, addresses.
4. [Images](images.md): where to put them, resizing, captions, share images, video.
5. [Languages](i18n.md): one or several languages, translations, adding an interface language.
6. [Customization](customization.md): palettes, colours, fonts, your own CSS, overriding templates.
7. [Features](features.md): search, terminal, rain theme, statistics, footer, webring.

## Publish

8. [GitHub Pages](deploy-github-pages.md): user site, project site, custom domain.
9. [Other hosts](deploy-server.md): Apache, nginx, SSH/rsync, Netlify, Cloudflare Pages, FTP.

## Maintain

10. [Updating](updating.md): new versions of the theme, Eleventy and Node.
11. [Migrating](migrating.md): from Jekyll, Hugo, Medium or WordPress.
12. [Troubleshooting](troubleshooting.md): build errors and their fix.
